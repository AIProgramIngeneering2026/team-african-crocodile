# team-african-crocodile

# Сервис выполнения заданий (базовый вариант)

## Сервис решит эти проблемы

Нам нужен единый, универсальный способ выполнения небольших вычислений по запросу, который позволял бы отслеживать результат и безопасно повторять операцию в случае сбоя. Без этого каждая такая операция превращается в отдельный скрипт или эндпоинт без сохранения состояния — без истории выполнения и возможности безопасного повторного запуска.
## Для кого этот сервис

- **Разработчики**, которым необходимо выполнять небольшие операции через единый API, вместо того чтобы интегрировать каждого поставщика услуг по отдельности.
- **Студенты и рецензенты** данного курса, использующие этот сервис в качестве эталонной реализации.
- **Научные исследователи**, проводящие экспериментальные измерения, которым требуются прослеживаемые, воспроизводимые преобразования величин и метеорологические данные.
- **Инженеры-строители**, которым необходимы точные измерения с корректным учетом единиц величин.

## Что входит и не входит в систему

- **Жизненный цикл задачи**: `created → running → done / error`; недопустимые переходы
  отклоняются ядром доменной логики.
- **Подключаемые инструменты, работающие по единому контракту** (интерфейс `Tool` + `Registry`):
  добавление нового инструмента не требует внесения изменений в диспетчер или управляющую логику.
  - **Конвертер величин** — преобразование значений между единицами измерения одной размерности:
    - температура (°C, °F, K) — использование канонических формул, настройка точности, опциональный
      расчет погрешностей;
    - длина (например, км → мили) — использование коэффициентов из реестра единиц измерения (точное значение:
      `1 км = 0,621371192237334 мили`), округление методом «половина вверх» (half-up);
    - отклонение запросов с несовместимыми размерностями (например, метры → килограммы) с указанием
      кода ошибки и списка допустимых вариантов преобразования.
- **Погода** — получение текущих погодных условий для заданного города через **API OpenWeatherMap**
  (температура, влажность, давление, скорость ветра); разрешение названий городов, валидация полей,
  кэширование с временем жизни (TTL) 10 минут.
- **Текстовый преобразователь** — выполнение трансформаций текста (например, приведение к формату Title-case,
  профиль `title-basic-v1`) с сохранением истории преобразований.

- **Хранилище с поддержкой миграций** для ведения истории задач и сохранения результатов
  (включая привязку к идентификаторам экспериментов или образцов).
- **Диагностика**: структурированные логи с использованием идентификаторов корреляции (correlation ID),
  проверка работоспособности (health check), конфигурация через переменные окружения.
